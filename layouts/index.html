oxrok

A sigrok-compatible stack in Rust for logic analyzers, scopes and meters: a library, drivers and a command line tool. It builds with cargo alone, links no C sigrok library, and takes sigrok-cli's flags, file formats, driver ids and decoder ids.

Experimental. Most drivers have never run on real hardware.

How it was written

oxrok is a translation of the sigrok C and Python code into Rust, done by a large language model, with a human directing the work: choosing what to port, reviewing the structure and the protocol handling, wiring up the bench hardware and running the comparisons. Read the code with that in mind, and read the driver table for what has met which kind of evidence.

How it is tested

Most of these drivers have never met their device, so the project's answer is a device model in Rust, attached through Linux's vhci-hcd over USB/IP: the kernel sees a real USB device, and the real sigrok-cli and oxrok run unmodified against it. Every transaction is logged and compared. The models are built to misbehave — stalls, unplugs, late replies, bad frames. The whole method, and what it cannot tell you.

The models run on vusb, a virtual USB library that puts a device on the bus that is only Rust code.
